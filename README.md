# Banking Widget

Виджет для банковских операций.

## Описание

Проект содержит функции для маскировки номеров банковских карт и счетов.


## 🔄 Генераторы для работы с транзакциями

Модуль `generators` предоставляет инструменты для эффективной работы с данными транзакций.

### filter_by_currency

Фильтрует транзакции по заданной валюте
